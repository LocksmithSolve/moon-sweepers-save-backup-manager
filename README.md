## 🛠️ Troubleshooting / Fix Workflow

1. Exit Moon Sweepers and let the game finish saving before working with files.
2. In Windows File Explorer open %USERPROFILE%\AppData\LocalLow\DragDropGames\MoonSweepers\Backups.
3. Copy the entire relevant backup folder to a separate dated directory or external drive; do not alter the only original copy.
4. Launch the updated game normally first and check whether its built-in repair restores the world.
5. For manual recovery, keep the current files intact and work only on a duplicate that matches the same game version.
6. Never attempt to downgrade a 1.0.4-created save to an older game version; the official patch states they are incompatible.
7. Document the world name, slot, date and game version with each backup.

## ❓ FAQ

**Where are backups stored?**  
Under AppData\LocalLow\DragDropGames\MoonSweepers\Backups; they are stored outside Steam Cloud.

**How many automatic backups exist?**  
Patch 1.0.4 keeps up to five full backups per save slot.

**Can I load a 1.0.4 world in 1.0.3?**  
No. The 1.0.4 patch notes explicitly say newer saves are incompatible with older builds.
